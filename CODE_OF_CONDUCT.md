# Code of Conduct

## Our standard

Contributors, maintainers, reviewers, and users are expected to communicate constructively and professionally. Technical disagreement is welcome; harassment, discrimination, personal attacks, intimidation, and knowingly disruptive behavior are not.

Contributions should focus on evidence, reproducibility, safety, interoperability, and the engineering problem under discussion. Respect different levels of experience and provide actionable feedback.

## Enforcement

Report unacceptable behavior privately to the repository maintainers through the contact channel listed in the GitHub repository. Include the relevant issue, pull request, or communication context. Maintainers may remove comments, close discussions, restrict participation, or take other actions needed to keep the project usable and safe.

Reports will be handled as confidentially as practical. This code of conduct applies to project spaces, issue trackers, pull requests, reviews, and project-related communication.
